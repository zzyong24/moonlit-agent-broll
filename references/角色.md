# 角色

## 先用用户已有角色

在用户自己的配置目录查角色库和已确认角色卡，确认这次选择的角色版本。Skill 不带角色图或示例角色；不把任何使用者的角色打包分享。

没有合适角色时给三条路，让用户选一种：

1. **上传自己的形象**：用已有设定板或多角度图，先确认可使用范围。
2. **用已有图片**：照片、草图或用户有权使用的角色图，以图为参考生成；保留用户指定的特征，不默认照搬背景或姿势。
3. **口述转文生图**：根据外观、材质、比例和画风描述出候选，让用户选定；别把未选候选当作正式角色。

不要使用第三方 IP 或未经同意的他人照片作底。看图、建角色与上传到视频服务是不同动作；仅供规划的图片不默认上传给模型服务。

## 选定后制作设定板

包含正面、侧面、背面、四分之三侧，若干表情、若干动作，以及一张干净全身图。每个视角都能核对核心特征，避免换姿势就换比例或材质。生成能力不足时，可由用户手动导入相应图片。

附一份简短角色卡：

- 稳定外观：轮廓、颜色、显著特征。
- 材质与身体比例：便于跨镜头核对。
- 禁止项：不能改变或出现的特征。
- 已确认版本与本次使用的参考图。

确认后的长期角色放用户配置目录；本项目选中的版本、用途和必要副本放项目 `.agent-broll/`。不要写到 skill 目录。

## 可跳过完整设定板

用户想直接做本片时，建临时角色卡并放项目 `.agent-broll/`：至少确定外观、材质、比例、禁止项和可用参考图。若无参考图，先依据口述生成并确定本片可复用的身份图。完整设定板以后可补，不把它设成使用门槛。

跳过设定板仍须审图片故事板。临时卡也应足以发现镜头间身份漂移，不能每格凭新描述另造一个角色。

## 身份与场景分开

角色卡约束身份，风格参考约束表现方式，首帧约束镜头起点。身份图的背景、表情、道具不一定适合本片，应记录取舍。相同角色可以进入不同场景；配角只有承担冲突、选择或规模含义时才加入。

## 月明团队固定角色

默认直接沿用用户配置的角色库目录中的积木人（四视角 + 表情图 + base.txt）。只有月明要求新角色时才走上面的三条路。本仓库不内置该目录的本机路径。
