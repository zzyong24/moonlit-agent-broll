# 接入别家模型

给 Agent 的一页接入说明。更换接入不自动更改已通过的选段、角色、故事板或创意。

1. **读那家的官方文档。** 查生成、查询、结果下载和计费说明；记录链接与核对日期。第三方文章不能代替接口依据。
2. **整理能力与计价。** 核实模型、模式、时长、分辨率、参考素材用途／数量、任务状态、结果字段及各计费项。查不到就写“未知”，不从秘塔套单价或猜限制。核实现金换算及实际账户档位；付费优化默认关闭。
3. **仿照 `providers/metaso_h3.json` 写新的接入。** 对齐该文件的结构与脚本实际用到的字段。秘塔专用的 `h3.py` 不保证支持别家协议：接口不同就建立该服务的最小执行入口，别把换域名当作完成接入。本轮不开发通用配置引擎。
4. **用假服务器自测。** 至少验证：无确认拒绝提交、正常完成、提交结果不明不重投、持有编号后恢复、下载失败仅重下、200 错误响应、空文件／网页拒绝、输出和记录无 Key、估价含所有计费项。请求前持久化，回执编号即时保存；不得自动重试创建任务。
5. **用户授权后做一次最小真实测试。** 先展示该次模型、模式、时长、分辨率、计费项、金额和剩余预算，由用户确认；素材传输也在本次指定范围内。比较返回内容、可用文件和实际扣费，未知项仍未知就如实保留。未经这次授权，不调用收费接口或试用真实 Key。

通过后告知用户：官方核到的能力、假服务器验证的行为、真实测试结果和仍未知的部分。接入能提交不等于画面质量、音频、计价或稳定性已通过验证。项目数据仍放 `.agent-broll/`，用户配置仍与 skill 安装目录隔离。
